# 🐚 ALU Shell Project: Loops, Conditions, and Parsing

This project is part of the **ALU - Introduction to Linux and IT Tools** course.  
It focuses on automating repetitive tasks using **Bash scripting** and mastering **loops, conditions, and parsing** concepts.

---

## 📘 Project Overview

The goal of this project is to understand how to:
- Use **loops** (`for`, `while`, `until`) in Bash
- Apply **conditional statements** (`if`, `elif`, `else`, `case`)
- Perform **file testing and parsing**
- Use **commands like `cut`, `awk`, and `sed`** for text processing
- Write clean, readable, and executable scripts that pass ShellCheck

### Prerequisites

- Tools installed: `awk`, `sed`, `grep`, `cut`
